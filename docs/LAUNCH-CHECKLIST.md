# Launch checklist

## Before public launch
- [ ] GitHub Pages enabled (Settings > Pages > Source: GitHub Actions)
- [ ] Supabase on a paid plan (free projects pause after a week of inactivity and forms stop working)
- [ ] `INGEST_SECRET` set in Supabase and GitHub; `ANTHROPIC_API_KEY` set in GitHub
- [ ] Content pipeline run in dry-run, then live; 300+ articles and 500+ profiles reviewed and published
- [ ] All placeholder content replaced; "sample" labels removed
- [ ] Prices confirmed; rate card and media pack issued
- [ ] Custom domain connected and `SITE_URL` / `PAGES_BASE_PATH` variables set
- [ ] Privacy policy, cookie notice and terms added (newsletter sign-up collects email addresses)
- [ ] Email platform chosen; sign-up confirmation and unsubscribe flow in place
- [ ] Payment link or checkout for subscriptions and listing upgrades
- [ ] Spam protection (CAPTCHA or rate limit) on the sign-up and enquiry forms

## Founding partners (pre-sell)
- [ ] 20 target firms named per sector in the UK
- [ ] Founding offer: 30% off for an annual commitment
- [ ] 5 to 10 signed before public launch
