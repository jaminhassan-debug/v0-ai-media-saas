# Sponsor rate card (illustrative)

All prices are **starting points to test with the market** before a media pack is issued. Founding partners receive 30% off annual commitments.

| Product | From | Includes |
|---|---|---|
| Directory listing: Featured | £1,500 / year | Priority placement, enquiry form, logo and full profile |
| Directory listing: Premium | £4,500 / year | Top placement in sector hubs, newsletter mentions, linked articles |
| Newsletter primary sponsor | £1,200 / issue | Top slot and logo in the weekly digest |
| Newsletter classified | £400 / issue | Short text placement for jobs, events or services |
| Display advertising | £35 CPM | Leaderboard (970x90) and MPU (300x250) across the site |
| Section sponsorship | £6,000 / quarter | Own News, Analysis, a sector hub or the regulatory tracker |
| Sponsored content | £3,500 each | Labelled partner-insight article with newsletter push |
| Report sponsorship | £8,000+ | Sponsor a ranking or research report |
| CPD webinar sponsorship | £2,500 | Co-hosted session with speaker slot |
| Roundtable host | £8,000 | Choose the theme; host the closed session; write-up with your name |
| Summit sponsorship | £4,000 to £20,000 | Packages by tier at the annual London summit |

## Editorial rules sponsors accept

- Sponsored content is labelled "Sponsored" with the sponsor's name and does not represent FWI's views.
- Sponsors cannot influence news or analysis coverage.
- Directory placement is by paid tier and is shown as such.
